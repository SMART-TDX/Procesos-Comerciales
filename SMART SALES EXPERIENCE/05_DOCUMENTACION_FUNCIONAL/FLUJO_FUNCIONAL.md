# Flujo funcional

CLIENTE → EJECUTIVO → CONOCE SMART → TU HISTORIA → DIAGNÓSTICO → NECESIDADES → RECOMENDACIÓN → SMART FLEX / SMART ONLINE → EXPERIENCIA DE PRODUCTO → REQUISITOS DEL CLIENTE → PRECÍERRE → FORMAS DE INICIO → INVERSIÓN → CALCULADORA → COTIZACIÓN → PDF → RESUMEN DE EXPERIENCIA.

## Recorrido común

La asesoría comienza con el nombre del cliente y la selección del ejecutivo. Continúa con escenas institucionales y un diagnóstico de perfil, relación actual con el idioma, objetivos y barreras. El motor de recomendación pondera respuestas y puede sugerir Smart Flex, Smart Online o mostrar una decisión mixta. El ejecutivo confirma el producto.

Después se presenta la experiencia del producto, se registran criterios de decisión y preferencias de inversión, y se realiza el precierre. El usuario identifica beneficios relevantes y favoritos antes de abrir la Calculadora Comercial embebida.

La calculadora obliga a elegir una combinación oficial. Al completar la cotización, la Experience recibe el resultado, muestra el cierre y permite regresar, abrir la cotización imprimible, consultar el resumen o iniciar otra asesoría.

## Smart Flex

Presenta módulos START a PRO, metodología, ciclo de aprendizaje, clases en vivo, grupos, Cambridge, autoestudio, SmartZone, horarios, constancia y preparación/certificación Linguaskill. En inversión, Hub solicita nivel de ingreso, modalidad comercial SCORE/MP cuando corresponda, plan, condición, forma de pago, cuotas y beneficios compatibles. Smart Flex requiere seleccionar al menos un E-Book disponible antes de continuar al resumen.

## Smart Online

Presenta rutas de inglés y francés, packs, beneficios digitales, certificación informativa, plataforma, autoestudio y requisitos técnicos. En inversión, Hub selecciona duración oficial, condición, pago, beneficios aplicables y resumen. Los planes se identifican por meses y por registros disponibles en el catálogo oficial.

## Cotización y PDF

La cotización reúne programa, condición, inversión, ahorro cuando aplica, beneficios y plan de pagos. La vista de impresión se abre en `print.html`; el usuario utiliza el diálogo del navegador para imprimir o guardar como PDF. No se genera el archivo PDF en un servidor.
