# Ejecución local

No existe instalación de dependencias de producción.

Opción directa: abrir `12_ENTREGA_EJECUTABLE/SMART_SALES_EXPERIENCE/index.html` en un navegador moderno.

Opción recomendada para IT: publicar temporalmente la carpeta `12_ENTREGA_EJECUTABLE` mediante cualquier servidor HTTP estático corporativo y abrir `/SMART_SALES_EXPERIENCE/index.html`. Mantener las carpetas Experience y Hub como hermanas.

No es necesario Node.js, una API, una base de datos ni acceso a internet para la lógica principal. Los enlaces a servicios externos sólo funcionan con conectividad.
