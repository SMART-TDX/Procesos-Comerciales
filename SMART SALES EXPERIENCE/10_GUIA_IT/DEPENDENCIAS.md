# Dependencias

## Runtime

- Navegador moderno con JavaScript habilitado.
- APIs estándar: DOM, `sessionStorage`, `postMessage`, `Intl`, `URLSearchParams`, `iframe`, `window.print`.
- MapLibre GL está incluido localmente en `SMART_SALES_EXPERIENCE/vendor/maplibre-gl`.

## No requeridas

- No Node.js para ejecutar la aplicación.
- No React, Angular ni Vue.
- No servidor de aplicación.
- No base de datos.
- No APIs externas para tarifas o planes.
- No Docker.

## Conectividad opcional

Enlaces como WhatsApp requieren internet al utilizarlos. Esto no afecta el cálculo local ni el catálogo.
