# Entrega técnica para IT

IT recibe dos aplicaciones front-end estáticas integradas, sus assets, datos comerciales, Excel fuente, documentación, validadores y configuración de publicación. No hay backend ni base de datos.

## Dónde revisar

- Código productivo: `01_CODIGO_PRODUCCION`.
- Reglas y datos: `03_DATOS_Y_REGLAS_COMERCIALES`.
- Arquitectura: `04_DOCUMENTACION_TECNICA/ARQUITECTURA_SISTEMA.md`.
- Flujo y productos: `05_DOCUMENTACION_FUNCIONAL`.
- Fuentes oficiales sin editar: `06_FUENTES_OFICIALES` y `09_RESPALDO_ORIGINALES`.
- Deploy: `07_CONFIGURACION_DEPLOY`.
- QA: `08_QA_Y_VALIDACIONES`.
- Ejecutable mínimo: `12_ENTREGA_EJECUTABLE`.

## Apertura

Abrir `12_ENTREGA_EJECUTABLE/SMART_SALES_EXPERIENCE/index.html`. Para una prueba más consistente, servir `12_ENTREGA_EJECUTABLE` con un servidor HTTP estático local y entrar por la ruta de Experience. No se requiere instalación de paquetes para producción.

## Producción vigente

La referencia productiva está asociada a Vercel `smart-sales-hub` y al dominio `smart-sales-hub.vercel.app`. Esta consolidación no publicó ni cambió ese entorno.

## Control de cambios

Tarifas, planes, beneficios y reglas no deben modificarse sin validación comercial y nueva ejecución de QA. Los Excel en fuentes oficiales y respaldo se consideran originales no modificables.
