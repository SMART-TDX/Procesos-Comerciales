# Guía de publicación

La unidad de publicación es el contenido de `12_ENTREGA_EJECUTABLE`. La raíz debe conservar:

```
SMART_SALES_EXPERIENCE/
SMART_SALES_HUB_PRODUCCION_FINAL/
vercel.json
.vercelignore
```

La redirección raíz actual apunta a Experience. Experience carga Hub mediante una ruta relativa hermana. Cambiar nombres, profundidad o Root Directory rompe esa relación si no se ajusta y valida el código.

Antes de publicar en cualquier infraestructura, IT debe repetir validadores, rastreo de rutas, flujos Flex/Online, cotización y PDF. Esta guía no autoriza cambios en producción ni reemplaza el proceso corporativo de aprobación.
